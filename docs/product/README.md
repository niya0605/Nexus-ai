# Product

**Purpose:** This folder contains the frozen **Product Specification** for
Nexus AI — product vision, functional and non-functional requirements,
user personas and stories, the complete feature list, MVP scope, and the
future roadmap.

**Expected files:** `PRODUCT_SPECIFICATION.md` (not yet added).

**Relationship to other documentation:** This is the top of the
documentation hierarchy. Every other document in `docs/` — UX,
architecture, database, and API — exists to implement decisions made
here. Nothing downstream should ever justify a product decision; if a
later document appears to conflict with this one, this one wins.
