# UX

**Purpose:** This folder contains the frozen **UX Specification** for
Nexus AI — information architecture, user journeys, the full screen
inventory, navigation and interaction design, the design system, and the
guiding UX principles.

**Expected files:** `UX_SPECIFICATION.md` (not yet added).

**Relationship to other documentation:** Translates the Product
Specification into the concrete user-facing experience. It constrains
the Technical Design Document (which must support the interactions
described here) and the frontend implementation directly — no screen or
interaction should be built that isn't described in this specification.
